# docs/img/ — capturas y diagramas

- Nombre: `AAAA-MM-DD-area-que-muestra.png` (ej.
  `2026-08-15-purga-ajustes.png`, `2026-08-13-etapa2-probar-embeddings.png`).
  La fecha es la de la captura, no la de hoy; así se sabe si sigue vigente.
- Formato: PNG para UI, SVG para diagramas si se puede (se ve en git).
  Tamaño razonable (<500 KB); recortar al área que importa.
- Sin datos personales: antes de guardar, tapar tokens, rutas con
  usuario, nombres de proyecto privados y topics de ntfy (son
  contraseñas). El repo se publica.
- Referenciar desde el doc o la bitácora con ruta relativa:
  `![Ajustes › purga](img/2026-08-15-purga-ajustes.png)`.
- Las capturas del README principal (pendiente de Oscar) también van
  aquí y el README las enlaza como `docs/img/...`.
